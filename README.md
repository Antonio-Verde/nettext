# International Debt Crisis Media Analysis: Network Science & Text Mining

An integrated Network Science and Text Mining study of how international debt crises are covered by two major financial newspapers, combining co-occurrence graph analysis with topic modeling and sentiment analysis.

## Overview

This project analyzes a corpus of **503 news articles** — 329 from the *Financial Times* and 174 from the *Wall Street Journal* — covering international debt crises from the 1980s Latin American crisis through the European sovereign debt crisis and more recent events. The goal is to compare how the two outlets frame these events, both structurally (which concepts cluster together, and how) and thematically (which topics and sentiments dominate each source).

The analysis runs in two parallel tracks that are brought together at the end:

- **Network Science**: builds term co-occurrence graphs from the corpus and studies their structure — centrality, cliques, community detection (with a robustness check via the `robin` package), a 3D layout, and a multilayer comparison that models FT and WSJ as separate but interconnected layers of the same semantic network.
- **Text Mining**: applies LDA topic modeling, correspondence analysis, and sentiment analysis to the same corpus, including a direct FT vs. WSJ sentiment comparison and a temporal view of how topics shift over time.

**The raw article corpus (roughly 1,000 PDF files, ~60 MB, mostly duplicated across three folders) is intentionally not included.** These are copyrighted Financial Times and Wall Street Journal articles, and redistributing them isn't appropriate — the `.gitignore` in this repo excludes them by name. If you want to keep a local copy for your own reproduction, keep it outside version control, or use Git LFS with an appropriately restricted remote.

The rendered HTML report and its supporting assets (bundled JS/CSS libraries, generated figures) from your original export aren't included here either, since they're large, auto-generated by Quarto, and easy to reproduce — see "Reproducing" below. If you'd like the browsable HTML version on GitHub Pages, that's easy to add once the corpus path is fixed.

## Reproducing the analysis

Before running either script or re-rendering the report, one thing needs fixing: both currently point to an absolute local path —

```r
readtext::readtext("C:/Users/rcarl/OneDrive/Desktop/Esame NetText/PDF UFFICIALI")
```

This won't work on any machine but the original one. Replace it with a relative path (e.g. `data/PDF UFFICIALI`, pointing at your own local, not-committed copy of the corpus) before running.

## Tools

R, with:
- **Network Science**: `readtext`, `quanteda`, `quanteda.textstats`, `igraph`, `robin` (partition robustness), `ggplot2`
- **Text Mining**: `readtext`, `tm`, `tidyverse`, `tidytext`, `topicmodels` (LDA), `wordcloud`, `FactoMineR` / `factoextra` (correspondence analysis), `RColorBrewer`, `stringr`
- Report rendered with **Quarto**
